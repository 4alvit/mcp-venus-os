# Code of conduct

Participation in MCP Venus OS is open to everyone. Treat contributors and users
with respect regardless of experience, identity, background or circumstances.
Give technical feedback about the work, explain concerns constructively, and
respect another person's time, privacy and right to decline a request.

Harassment, threats, discriminatory remarks, sexualized attention, deliberate
intimidation, publishing private information without consent, and repeated
personal attacks are unacceptable. Do not post credentials, household data or
private conversations in an issue or pull request.

This policy applies to the repository, its issues, pull requests and other
spaces where someone represents the project. The maintainer may edit or remove
harmful content, limit participation temporarily, or ban persistent or severe
misconduct. Enforcement should be proportionate and explained to the affected
person where safe; private information is not part of a public explanation.

For a GitHub safety or abuse issue, use GitHub's **Report abuse** controls,
including when a report concerns the maintainer. For a non-confidential project
moderation request, contact the maintainer through an issue without posting
private details. Do not turn a confidential report into a public issue.
Security vulnerability reports use [SECURITY.md](SECURITY.md).

The maintainer should acknowledge a report, hear the relevant context, avoid
retaliation, and protect reporter confidentiality as far as reasonably
possible. A non-confidential project moderation appeal can be raised in an
issue with new information or a clear explanation of the concern. For a GitHub
safety decision, use GitHub's support and appeal process. No independent project
appeal panel or private project moderation mailbox is currently claimed.
